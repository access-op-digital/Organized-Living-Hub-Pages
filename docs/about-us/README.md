# About Us page

Built on 2026-10-08 for `organizedliving.com/company/about-us`. Staging copy:
`/company/about-us`. The copy matches the client-review document
`About Us - Organized Living.docx`; both are rendered from one content model.

## Brief

The Page Level Plan marks this URL **NO SEARCH TARGET**: a brand and trust page,
kept indexed, with no keyword. Search Console showed 81,733 impressions and 90
clicks in the 16 months to 9 August 2026, and Ahrefs listed no organic keyword
for the URL on 7 October 2026. The rewrite answers who Organized Living is in a
way search engines, answer engines and a Builder's procurement team can verify,
and routes each audience to its own next step, as the client's brief asks.
